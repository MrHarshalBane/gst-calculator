🚀 Key Features Built
🇮🇳 2026+ GST Slabs & Custom Rates:
Quick rate selection pills for 0% (Nil), 3% (Gold & Jewellery), 5% (Merit), 12%, 18% (Standard), 28%, 40% (Sin/Luxury Rate - Tobacco, >350cc bikes, gaming), and Custom % input.
🔄 Exclusive (+ GST) & Inclusive (- GST) Modes:
Exclusive Mode: Calculates GST amount to be added to net base price.
Inclusive Mode: Extracts net base price and tax portion from gross total.
🏢 Intra-State vs Inter-State Tax Split:
Intra-State: Splits tax into equal CGST (Central GST) + SGST/UTGST (State GST).
Inter-State: Applies full IGST (Integrated GST).
🧾 Multi-Item Invoice Builder:
Add multiple items with custom prices, quantities, and rates to generate a full invoice summary table with total taxable value and grand total.
🔍 HSN / SAC Code Finder:
Built-in searchable lookup database for official Goods (HSN) & Services (SAC) codes and standard rates.
📊 Visual Doughnut Chart & Formula Explanations:
Interactive breakdown chart powered by Chart.js and step-by-step math calculation boxes.
🖨️ PDF Export & Clipboard Copy:
Print-ready invoice view and one-click formatted plain text summary exporter for WhatsApp & email sharing.
🌙 Light / Dark Theme:
Glassmorphism design with theme toggle and saved user preferences.
